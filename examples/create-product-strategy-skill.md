# Example: Create A Product Strategy Skill

User:

> 我想做一个帮创业者判断产品方向的 skill。

Dao response shape:

```md
## 一：本源问题
表层需求：产品方向判断 skill。
根问题：创业者需要在信息不完整、资源有限、情绪波动时做出更少后悔的关键判断。
第一性原理：判断质量来自约束、证据、可逆性和对最大不确定性的验证。
成功标准：用户能得到一个可执行的最小验证实验，而不是泛泛建议。
不该做什么：不要直接替用户拍脑袋选方向。

## 二：核心张力
阳面：快速行动，抓住机会。
阴面：控制风险，避免自嗨。
平衡原则：用最小可逆实验验证最大不确定性。

## 万物：生成方案
skill 名称：startup-product-judgment
核心流程：决策类型识别 -> 假设拆解 -> 风险排序 -> 最小实验 -> 决策建议。
```
