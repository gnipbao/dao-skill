# Example: Create A Colleague-Style Skill

User:

> 我有一个特别厉害的运营同事，想把她的工作方式做成 skill。

Dao response shape:

```md
## 道：原始混沌
用户表层表达：想复制一位运营同事的能力。
用户可能真正关心：把隐性的工作判断、协作方式、交付标准变成可复用流程。
当前不确定点：是否有她的文档、聊天记录、交付物样本。
是否需要追问：是。

## 一：本源问题
根问题：如何从真实工作痕迹中复原一个人的判断模型，而不是只总结岗位职责。
第一性原理：同事类 skill 的材料必须来自实际工件，不能凭人格想象。

## 二：核心张力
阳面：复原人味和协作风格。
阴面：抽象成可复制的流程。
平衡原则：先提取可观察行为，再总结判断原则。

## 三：三才结构
天：忠于材料，不神化个人。
地：适用于工作资料充足的角色复制；不适用于没有样本的空想。
人：先收集材料，再生成协作协议、输出模板和决策规则。

## 万物：生成方案
推荐生成物：Colleague-style working-model skill。
```
