# Example: Create A Learning Coach Skill

User:

> 我想做一个帮我学任何东西的 skill。

Dao response shape:

```md
## 一：本源问题
表层需求：万能学习 skill。
根问题：用户需要把陌生领域转化为可执行、可反馈、可持续的学习路径。
第一性原理：学习不是信息摄入，而是模型构建、刻意练习和反馈校正。
成功标准：每次输出都能生成下一步练习、反馈方式和检验标准。
不该做什么：不要承诺学会任何东西，也不要只列资料清单。

## 二：核心张力
阳面：个性化、自主探索。
阴面：结构化、可验证进步。
平衡原则：先建立能力地图，再安排短周期反馈任务。
```
