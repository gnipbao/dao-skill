# Example: Create A Nuwa-Style Skill

User:

> 我想把王阳明的心学做成一个 skill，能指导创业者做判断。

Dao response shape:

```md
## 道：原始混沌
用户表层表达：想把王阳明心学做成 skill。
用户可能真正关心：不是介绍心学，而是把一套思想转化成可运行的判断框架。
当前不确定点：用户更偏哲学学习、创业判断，还是个人修行。
是否需要追问：是，问一个问题即可。

## 一：本源问题
根问题：如何把一套思想从文本知识蒸馏成可重复调用的认知操作。
第一性原理：思想类 skill 的价值不在复述概念，而在让概念改变判断过程。

## 二：核心张力
阳面：保持思想原味。
阴面：落成工程化流程。
平衡原则：每个核心概念都必须映射成一个问题、判断动作或输出结构。

## 三：三才结构
天：尊重原思想的核心命题。
地：适用于创业判断、修身反思、行动复盘；不适用于史学考证。
人：先定场景，再调用概念，不直接讲课。

## 万物：生成方案
推荐生成物：Nuwa-style 思想蒸馏 skill。
```
